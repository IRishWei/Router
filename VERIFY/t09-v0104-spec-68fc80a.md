# 结论：PASS（源码）；T09 实际验收仍 BLOCK/OPEN

## Findings

未发现阻断问题或可操作的 Spec 偏差。

## 需求符合度

- 官方要求“Preserve the actual HTTP status, response body shape, error code when present, and request ID”。`src/chatgpt-responses.mjs:270-303,699-725` 仅对精确 `application/json` 读取最多 64 KiB，输出固定 body-shape、官方九种 code 与请求字段白名单；不暴露 message/detail/response/body/token/cause，且保留 200 与 request ID。
- `src/chatgpt-responses.mjs:246-268,671-705` 将原 Task signal 与 transport 的同一绝对 120 秒 deadline 用于每次 body `next()`；超时、取消、畸形 chunk 均受控失败，计时器/监听器在 `finally` 清理，响应在 `:724-725` 关闭。
- `src/chatgpt-responses.mjs:700-711` 对非 SSE 始终返回 `INVALID_RESPONSE`；SSE 成功仍须 `response.completed`。本提交未增加重试、fallback、刷新或额外模型请求，未知 usage 仍不生成数值。

## 测试与验证缺口

独立执行三个 T09 定向文件：23/23 PASS；覆盖九种 code、未知字段、敏感值不泄露、超限、取消、非 JSON 不读 body、CONNECT 两次调用各一次请求及关闭。尚缺显式的停滞 iterator 超时和非字节 chunk 回归用例；实现路径可静态确认，但建议后续补测。

## 剩余风险

这些受控测试只证明安全诊断，不证明目标服务真实可用。现有实际请求仍未取得 `response.completed`，因此 AC4 与 T09 整体保持 BLOCK/OPEN。
