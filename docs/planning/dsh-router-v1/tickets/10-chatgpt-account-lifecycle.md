# T10：ChatGPT 续期、切换账号与退出恢复



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

授权连接可重启恢复、串行续期、切换账号及退出，失败时任务得到清晰暂停原因。

## Acceptance criteria

- [ ] 按账号/注册身份保存并恢复授权，切换后刷新目录，避免不同账号 client/token 混用。
- [ ] 续期串行化并原子保留替换凭据；并发任务、重启与刷新失败不会覆盖新状态。
- [ ] 账号撤销、权限变化和额度错误准确呈现；不反复登录或由超限错误推断全套餐耗尽和重置时刻。
- [ ] 退出停止新调用、按官方契约撤销并清理本地凭据；撤销未确认时明确显示，不影响其他账号。
- [ ] 通过完整任务覆盖到期→续期→继续、切换→选择、撤销→暂停；真实桌面生命周期验证与受控错误验证分别记录。
