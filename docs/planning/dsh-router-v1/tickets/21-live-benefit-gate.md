# T21：真实对照实验与继续开发门槛



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在批准预算内执行真实四类对照，给出继续自研、转为集成或停止路由层的证据结论。

## Acceptance criteria

- [ ] 实验有明确用户启用和整体预算，使用冻结输入、可比模型池/配置及可复现真实请求，达到限制停止。
- [ ] 分别报告固定低成本、固定强模型和社区对照；社区无法兼容则报告限制，不把不可运行当作胜出。
- [ ] 各类质量单独检查；只在可比完整费用/耗时下判断至少一项改善 15%、另一项退化不超过 10%。
- [ ] 失败、无法确认、未知费用和随机波动均展示，不能挑成功样例或以代理评审证明整体主观质量。
- [ ] 报告性能与实际交互差异、限制、数据充分性及继续/复用/停止决定；证据不足也能形成诚实报告，但不记为效果达标。
- [ ] 结论是后续真实策略试用/发布的额外条件：本票关闭不等于允许继续；若停止或改变范围，先调整后续计划，不修改父规格。
