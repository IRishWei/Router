# T17：稳定边界接管与完整上下文交接



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

咨询后仍受阻或需要重新规划时，由另一模型接续同一任务，保留可靠上下文。

## Acceptance criteria

- [ ] 接管依据与目标候选可观察，遵守固定选择、启用池与预算，自动切换不写全局默认。
- [ ] 携带完整可跨模型对话、用户约束、文本/图像和已完成工具记录；不直接互换提供商私有字段。
- [ ] 调用前校验容量、工具协议与模态，不兼容则取消并保留有效当前状态或明确暂停。
- [ ] 在稳定请求边界应用，不打断未完成工具或混合配置；无新证据不来回接管。
- [ ] 接管模型完成任务后重新验收、同一账本记录全部开销；不新建独立任务。
- [ ] 完整任务验证跨模型交接、图像/工具记录、容量不足、格式不兼容和重复副作用防护；首版无压缩/静默截断。
