# T11：订阅参考价值与额度未知状态



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

订阅任务展示 token、可信映射下的 API 参考价值及额度状态，缺失信息保持未知。

## Acceptance criteria

- [ ] 按实际返回用量和可信同模型价格映射计算订阅参考价值，保留来源、日期和映射置信度。
- [ ] 实际支出、API 费用计算、订阅参考价值和额度状态分开，参考值不冒充账单。
- [ ] 缺失 token、价格映射或可信额度占比显示未知，不按零或插件局部 token 累计推断账号整体百分比。
- [ ] 仅在有公开可信数据时使用额度比例影响稀缺性；无公开契约时正常降级，不访问私有订阅接口。
- [ ] 费用未知场景只执行已明确的限制；不能用缺失数据证明现金节省。
- [ ] 用完整任务验证已知映射、别名不明、缓存/推理子项及额度缺失，界面说明为何有或没有估算。
