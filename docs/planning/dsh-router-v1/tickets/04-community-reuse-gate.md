## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在目标桌面验证最接近社区方案的最小任务路径，给出可复用能力及后续实现边界。

## Acceptance criteria

- [ ] 检查 oh-my-dsh 的实际安装/加载、配置和同会话选择路径，使用可控模型验证可运行范围；不能将旧 peer 声明当作 rc.2 兼容证明。
- [ ] 核实可复用组件的公开契约和许可条件，区分源码已实现、桌面已验证与未验证功能。
- [ ] 给出安装→配置→任务执行的可复现证据；若无法运行，保留失败原因与最小适配范围，不因其失败宣称本项目更优。
- [ ] 说明咨询、阶段切换、设置页已有重合；独立列出验收证据与效果评估等候选差异。
- [ ] 产出继续验证自研、复用接入组件或需调整范围的明确决定；不在本票大规模移植整个社区项目。
- [ ] 无隐蔽付费调用，不修改或关闭父规格。
