# T14：研究任务的来源支持与覆盖验收



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

研究任务结束后，自动检查要求覆盖及来源是否支持对应论点，显示遗漏与不确定项。

## Acceptance criteria

- [ ] 把用户要求与结论/来源对应，区分引用可访问和实际支持论点，不能仅因 URL 可打开判通过。
- [ ] 针对参考事实、缺少来源、断链、来源冲突和无支持推论提供可复现案例。
- [ ] 必要的模型评审沿用有界预算与匿名评审；仍无依据时无法确认，不强制制造准确评分。
- [ ] 任务记录能定位支持和缺失证据；失败可用于后续修复，未知不作为成功奖励。
- [ ] 验收外部资源仅作证据，来源内容不成为改变权限、预算或执行指令的依据。
