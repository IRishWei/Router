# T18：整条任务链的故障恢复与暂停



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

执行、咨询或接管出错时有限恢复，必要时暂停，并保留任务结果与可追溯状态。

## Acceptance criteria

- [ ] 连接失败有限重试，允许时使用已启用且能力/预算满足的替代模型；手动固定不自动替换。
- [ ] 网络、限流、授权与任务困难分开，不改变实际错误或绕过用户计费路径。
- [ ] 流中断、未完成响应、凭据撤销和未知用量不记成功，不盲目重复可能有副作用的操作。
- [ ] 插件可捕获异常暂停本任务路由，显示原因并尽量保留原生路径；不承诺恢复进程崩溃。
- [ ] 重新授权、预算不足或交接失败有明确恢复/停止入口，状态不因重试丢失。
- [ ] 从完整任务验证执行/咨询/接管各阶段故障、OAuth 失效、重启和重复操作；真实与模拟证据分开。
