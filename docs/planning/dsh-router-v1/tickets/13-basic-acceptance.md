# T13：编程、写作验收与有条件模型评审



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

完成编程或写作任务后自动检查明确要求，必要时有界评审，并展示证据支持的终态。

## Acceptance criteria

- [ ] 编程按行为要求、必要测试/构建检查；写作按长度、结构、必含/禁止项及明确评审标准检查。
- [ ] 统一展示检查覆盖、证据来源、通过/失败/无法确认，不以响应完成或构建成功代替全部验收。
- [ ] 证据不足或风险较高才调用匿名评审，消耗计入任务；必要时最多追加一次复核。
- [ ] 评审冲突、预算不足或未覆盖质量保持无法确认，产物仍可查看，不声称整体质量保证。
- [ ] 模型给出的无支持成功判断不覆盖真实失败；结果可供后续咨询和学习读取。
- [ ] 从任务提交到产物及记录测试明确成功、失败、部分覆盖、评审冲突和超限分支。
