# T03：完整任务记账、预算预留与超限暂停



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

任务内所有调用产生可追溯消耗，预计下一次调用超限时暂停，允许用户扩展同一任务预算。

## Acceptance criteria

- [ ] 显示 task 级 token、耗时和 API 费用计算结果，保留价格来源/日期/币种及估算或账单确认标识。
- [ ] 覆盖输入、输出、缓存与推理子项，避免重复计费；不同币种无可信换算时不直接合计。
- [ ] 判断、执行、评审、咨询、重试及重做使用统一记账入口；失败用量不明保留未知，不按零计算。
- [ ] 调用前预留、返回后核对；预计超限不发请求，界面可选择延长预算或停止，任务身份与原记录不重置。
- [ ] 执行中补充/纠正仍属于同一任务；请求超过估算时报告实际消耗，不承诺绝对账单硬上限。
- [ ] 无法估价时明确哪些金额限制不可执行，只使用已明确的限制；以可控完整任务验证上述分支。
