# T12：轻量判断与起始模型自动选择



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

提交任务后，插件筛选已启用且兼容的模型，按目标选择起始模型并显示理由。

## Acceptance criteria

- [ ] 利用已有任务要求、模态、工具、上下文和本地观察，不为每个任务强制强模型规划或扫描全项目。
- [ ] 需要语义判断时使用已启用模型池中的有界调用，记录消耗；预算不足不隐蔽调用。
- [ ] 先筛授权、启用池、能力与容量，再比较均衡/费用/token/速度/质量目标；低价不等于能胜任。
- [ ] 未知能力/价格/用量有明确处理，保守先验不冒充实测质量；可选校准先显示预算。
- [ ] 当前模型、理由、判断消耗和候选排除原因可观察；单候选执行、无候选暂停、固定模型不被覆盖。
- [ ] 完整任务验证文本/模态要求、目标差异、冷启动与补充信息，遵循早期社区复用决定。
