## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

任务结束后本地记录可验证结果，显示候选策略的影子选择及差异，不额外执行候选模型。

## Acceptance criteria

- [ ] 记录类别、配置/模型/策略版本、验收证据、用量和耗时，学习数据留本地。
- [ ] 默认观察与影子计算不创建额外模型调用或付费任务回放；显示未执行候选不能证明质量。
- [ ] 无法确认不作为成功奖励，未知消耗不转成零，按任务类别与条件保留可比性。
- [ ] 界面可查看观察/影子状态、关闭学习并恢复原策略；保留历史版本和解释依据。
- [ ] 完整任务验证四类结果归集、候选差异、重启与用户池/固定/预算限制；不在本票自动扩大真实采用。
