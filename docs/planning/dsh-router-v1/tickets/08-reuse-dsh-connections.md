# T08：发现并引用已有 DSH 连接



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

插件列出可通过公开宿主契约复用的已有连接，用户启用后可完成任务。

## Acceptance criteria

- [ ] 仅通过宿主公开契约发现/引用连接，不复制或读出其他工具的认证秘密。
- [ ] 界面显示来源、支持范围和未知能力；不支持的社区 provider 明确说明，避免全兼容承诺。
- [ ] 用户主动启用候选后执行完整任务，实际请求与账本一致；未启用连接不调用。
- [ ] 宿主端删除、修改或断开连接安全反映到候选状态，遵守稳定边界与手动固定。
- [ ] 使用可控宿主连接与至少一条目标桌面可复用路径验证发现→启用→执行→移除，缺少实际契约时保留不支持证据。
