# T02：模型池管理、手动固定与配置生效



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在界面启用两个可控模型、固定执行模型，并看到运行中修改何时生效。

## Acceptance criteria

- [ ] 连接与模型页可勾选或移除可控候选，记录能力和兼容性是已知、声明还是未知；未启用模型不能收到请求。
- [ ] 路由与预算页提供自动路由开关和手动固定；固定后不得自动跨模型替换。
- [ ] 执行中修改以配置版本标记待生效，下一稳定请求边界应用；流式请求或待完成工具不混用新旧配置。
- [ ] 断开/移除当前模型不会静默改变正在执行的请求；后续无有效候选时说明原因并暂停。
- [ ] 仅有一个候选允许单模型执行，零个兼容候选明确报出缺少条件；重启保留启用池和设置。
- [ ] 以完整任务验证池限制、固定选择、待生效/已生效及禁用路由后仍可管理设置。
