## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在最终批准范围内验证安装、首次配置、任务执行、学习、重启恢复和卸载，交付可安装版本。

## Acceptance criteria

- [ ] 仅在效果结论及范围允许发布时推进；停止或转集成结论先更新计划，不能机械继续。
- [ ] 验证干净桌面安装、启用、三页配置、四类任务、咨询/接管、预算、学习控制、重启、暂停恢复和卸载。
- [ ] 所有宣称支持的来源有实际目标宿主证据，失败或不可用资格明确展示，不以模拟冒充认证。
- [ ] 检查版本/Framework 兼容、原生与自动选择一致、全局默认不被改写及 Codex 配置/认证未被访问。
- [ ] 交付可通过桌面管理安装的 bundle、已知限制和可复现效果报告；不保证未测试平台、零重启或每任务收益。
- [ ] 本票不关闭或修改父规格；明确记录完成范围、未解决限制及安装恢复路径。
