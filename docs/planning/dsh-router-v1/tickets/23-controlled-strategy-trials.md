# T23：小范围真实策略试用、采用与回退



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

用户一次性开启后，以不超过 5% 的初始比例试用候选策略，证据达标才扩大，退化时回退。

## Acceptance criteria

- [ ] 仅在真实效果门槛给出允许继续的结论、且用户显式开启后试用；不将前置票关闭视为自动授权。
- [ ] 初始比例不超过 5%，符合能力/预算，固定候选版本；属于正常任务执行，不重复原任务付费回放。
- [ ] 以任务类别和可比条件收集证据，证据不足或无法确认不支持扩大采用，按正式门槛评估收益。
- [ ] 明确退化触发回退或停止扩大；界面解释策略变化并允许关闭试用/学习及恢复原策略。
- [ ] 学习不改账号权限、模型池、手动固定或预算；试用的全部调用正常记账。
- [ ] 通过完整任务序列验证比例边界、启用/停用、不足证据、回退及重启，不以影子成绩替代真实质量。
