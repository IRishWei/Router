# T05：DeepSeek API 连接到完整任务



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在插件界面配置 DeepSeek API、发现候选并完成可记账任务。

## Acceptance criteria

- [ ] 在 Host 保护的存储中保存连接，界面支持输入凭据、检测、模型选择、断开与重连；普通记录不含秘密。
- [ ] 模型发现和能力状态明确区分；登录/检测成功不等于每个模型已具备全部能力。
- [ ] 实际任务调用通过模型池和统一预算入口，结果、用量、费用置信度及错误显示在任务记录。
- [ ] 连接检测若消耗资源，先明确展示并计入检测消耗，不隐蔽探测全部模型。
- [ ] 提供受控端点测试及目标桌面一次经授权、受预算限制的真实完成请求证据；缺少凭据时报告待验证，不能用模拟认证真实接入。
- [ ] 覆盖错误凭据、断流、重启持久化与退出后不可再调用；保持 Codex 隔离。
