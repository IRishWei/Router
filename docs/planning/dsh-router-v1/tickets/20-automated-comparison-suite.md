# T20：四类任务的冻结样例与自动对照报告



## Parent

[首版规格 #1](https://github.com/IRishWei/Router/issues/1)

## What to build

在界面启动可控的四类对照实验，生成包含失败和未知的完整报告，建立真实评估入口。

## Acceptance criteria

- [ ] 实验前冻结任务/输入/验收/评审/价格/策略，覆盖编程、写作、研究、图像及不同难度/升级路径。
- [ ] 使用同一完整任务入口运行低成本、强模型、候选路由和可适用社区方案；成对重复并记录配置差异。
- [ ] 模型/策略身份对评审隐藏，明确检查与主观评分分开；无法确认、失败和未知费用保留。
- [ ] 报告各类质量、样本数、不确定性、消耗/耗时分布；策略内评审计入任务，共同外部评审单列。
- [ ] 在三页界面内提供实验预算、启动、暂停与结果查看，不默认进行真实付费回放。
- [ ] 可控样例验证 15%/10% 门槛计算和证据不足分支；模拟报告明确标模拟，不能认证真实效率。
