# Triage Labels

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 AI 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不处理 |

技能提及任务状态时，使用本表对应的 GitHub 标签。
